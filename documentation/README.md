# Gyre Documentation Site

This folder contains the Docusaurus site published at [entropy0120.github.io/gyre](https://entropy0120.github.io/gyre/).

## Work locally

Install dependencies from the repository root, then start the site:

```sh
pnpm install
pnpm --dir documentation start
```

Open the local URL printed by Docusaurus. To validate a documentation change, run `pnpm docs:check` from the repository root; it typechecks and builds the site.

## Add or edit a page

Add Markdown or MDX under `docs/`. The autogenerated sidebar includes pages from that folder; use frontmatter such as `sidebar_position` when ordering matters. Update `sidebars.ts` only if the navigation needs to stop being autogenerated.

Custom React pages and components live in `src/`; images, icons, and other static assets live in `static/`. Site configuration is in `docusaurus.config.ts`.

## Deployment

The GitHub Actions workflow builds and publishes the site to GitHub Pages when files under `documentation/` change on `main`, or when manually dispatched.
